# 手机上「自定义名字显示」保姆级操作指南

这份指南教你在手机上，让 LivePocket 页面里显示的名字**在你自己的手机上**变成你想要的文字或 emoji。

> 重要前提：这只改**你这台手机上看到的样子**，服务器里的真实数据不会变，别人看到的也不会变。纯粹是给自己看着开心 🎈

全程分两大步：
1. **一次性安装**（有点麻烦，建议请家里年轻人帮忙弄一次，以后就不用再弄了）
2. **日常使用**（很简单，自己就能操作）

---

## 一、先搞清楚你用的是哪种手机

- **苹果手机（iPhone / iPad）** → 看【第二章】
- **安卓手机（华为、小米、OPPO、vivo、三星等）** → 看【第三章】

---

## 二、苹果手机（iPhone）

### 第 1 步：下载一个叫「Userscripts」的免费 App

1. 打开手机上的 **App Store**（蓝色的、里面有个白色「A」的图标）。
2. 在搜索框里输入：**Userscripts**
3. 找到图标是 **蓝底白色 `</>`** 的那个（名字就叫 Userscripts），点 **获取 / 下载**，装上。（免费）

### 第 2 步：在「设置」里把它打开

1. 回到手机桌面，打开 **「设置」**（灰色齿轮图标）。
2. 一直往下滑，找到 **Safari**，点进去。
3. 找到 **「扩展」**，点进去。
4. 找到 **Userscripts**，把开关打到 **绿色（开）**。
5. 点一下 Userscripts，把下面网站权限里的 **livepocket.jp** 设为 **「允许」**（如果看到「所有网站」，选允许也可以）。

### 第 3 步：把脚本放进去

脚本就是前面那段代码，文件在电脑这个项目里：
`userscripts/livepocket-name-emoji.user.js`

最省事的做法是 **复制粘贴**：

1. 打开 Safari 浏览器。
2. 随便打开一个网页，看地址栏左边，点那个 **「ᴀA」** 或 **拼图🧩** 的小图标。
3. 在弹出的菜单里点 **Userscripts**，再点里面的 **「＋ / 新建脚本（New）」**。
4. 把那段脚本代码 **从头到尾整段复制**，粘贴进去。
5. 点 **保存（Save / 对勾✓）**。

> 拿不到代码？让帮你的人把 `livepocket-name-emoji.user.js` 文件内容发到你微信里，你长按全选复制即可。

### 第 4 步：完成！

打开 LivePocket 页面，右下角会出现一个 **🎭 小圆按钮**，说明装好了。怎么用看【第四章】。

## 三、安卓手机（更简单）

安卓上我们用 **火狐浏览器（Firefox）**，它能直接装插件。

### 第 1 步：下载火狐浏览器

1. 打开手机的 **应用商店**（华为应用市场 / 小米应用商店 / 应用宝等）。
2. 搜索 **火狐 / Firefox**，下载安装（橙色小狐狸图标，免费）。

### 第 2 步：在火狐里装「Tampermonkey」插件

1. 打开火狐浏览器。
2. 点右下角（或右上角）的 **三个点 ⋮** 菜单。
3. 点 **「扩展 / Add-ons」**。
4. 搜索 **Tampermonkey**，点 **添加 / 安装**。装好后它会问要不要允许，点 **允许**。

### 第 3 步：把脚本放进去

1. 把脚本文件 `livepocket-name-emoji.user.js` 的内容准备好（让人发到你微信也行）。
2. 火狐右上角三个点 → 找到 **Tampermonkey** 点开 → 点 **「+ 新建脚本 / Create a new script」**。
3. 把代码 **整段粘贴**进去，点 **保存**（软盘💾图标或菜单里的 File → Save）。

### 第 4 步：完成！

用火狐打开 LivePocket 页面，右下角出现 **🎭 小圆按钮** 就成功了。怎么用看【第四章】。

---

## 四、怎么用（苹果、安卓都一样，很简单）

1. 用装好脚本的浏览器打开 LivePocket，登录进自己的页面。
2. 看屏幕 **右下角**，有个 **🎭 圆按钮**，**点它**。
3. 会弹出一个小窗，有几个输入框：

   | 框 | 填什么 |
   |---|---|
   | **原姓（要被替换的）** | 你现在页面上显示的姓，比如 `山田` |
   | **原名（可留空）** | 你现在显示的名字（没有就不填） |
   | **显示姓** | 想变成的样子，比如 `🐢` 或 `龙猫` |
   | **显示名** | 想变成的样子（可留空） |

4. **一边打字，页面上的名字就一边跟着变**，所见即所得。
5. 想变回真名：把上面的 **「启用替换」** 开关关掉即可；想再变回去就再打开。
6. 填好的内容**会自动记住**，关掉浏览器、第二天再打开也还在，不用重填。

## 五、常见问题

**Q：名字没变？**
- 先确认右下角有没有 🎭 按钮。没有的话，说明脚本没装好或没对这个网站开权限，回到安装步骤再检查一遍。
- 「原姓」要和页面上**现在真正显示**的字一模一样（包括是不是繁体字），差一个字都找不到。

**Q：把别的地方的字也误改了？**
- 如果你的姓很常见，可能页面别处相同的字也被换了。告诉帮你的人「需要按元素限定」，可以改成只换名字那一处。

**Q：这样会不会把我账号弄坏 / 被发现？**
- 不会。它只改你这台手机屏幕上显示出来的样子，**没有向服务器发任何东西**，真实资料一个字没动。关掉脚本一切照旧。

**Q：换了手机 / 换了浏览器怎么没了？**
- 这是本机设置，只存在装过脚本的那个浏览器里。换设备需要重新按上面装一次。
